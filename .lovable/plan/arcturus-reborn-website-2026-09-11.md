# Arcturus Reborn Website

## Goal
Build a cinematic one-page Minecraft Factions server website that presents Arcturus as the no-staff, freedom-first alternative and makes joining the server immediate.

## Experience
- Full-screen opening scene using the supplied night-city screenshot, with a bold Arcturus Reborn title and prominent copyable server address.
- Dark obsidian interface with icy cyan, warm torchlight, and restrained red accents drawn from the screenshots.
- Strong block-inspired display typography paired with a clean readable body font.
- Sticky navigation linking to About, Features, Gallery, Comparison, and Discord.
- Scroll-triggered reveals, subtle image depth, animated status indicators, and reduced-motion support.

## Content
- Introduce Arcturus as a Java cracked Factions server supporting versions 1.8–1.20.
- Highlight classic 1.8 PvP, custom enchants, no moderation, no staff, and freedom-focused play.
- Use all four supplied screenshots across the opening scene and gallery.
- Include a direct comparison section contrasting laggy, unsupported servers with Arcturus.
- Add join instructions and one-click copy actions for `play.arcturusmc.org` and `arcturusmc.org`.
- Keep Discord as a visible action without inventing a destination; clearly mark it as coming soon until a link is provided.

## Technical details
- Store the supplied screenshots as project media through Lovable Assets.
- Implement the page at `/` with semantic sections, accessible controls, image alt text, and mobile layouts.
- Add route-specific title, description, Open Graph, and Twitter metadata.
- Define the visual system in the global theme tokens and load selected web fonts from the document head.
- Verify the live page at desktop and mobile widths, including copy interactions and scroll behavior.
